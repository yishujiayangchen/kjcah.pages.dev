# 看尽长安花｜长安城市探索游戏

本版本将网站定位调整为“长安城市探索游戏”。

## 入口
- index.html：仅保留游戏/网站介绍与入口
- changan-night.html：独立“长安夜”界面
- city-events.html：独立“城中事”界面
- flower-poetry.html：独立“花间诗”界面
- changan-jishi.html：独立的地点与人物选择界面（已移除城市地图）

## 地点与人物交互
- 地点按钮：点击进入对应坊市探索页面
- 人物按钮：点击直接进入独立人物故事页
- 原城市地图已移除
- 昼夜切换：影响天空与地图亮度
- 灯笼动画：夜间持续摇曳与呼吸
- 马车动画：沿主街循环行驶
- 随机路人：持续生成并移动
- 隐藏事件：按钮随机触发城市小事件

## 已有深度内容
5 个坊市、15 个独立人物故事页面，以及对应的酒楼/客栈/商铺探索。
