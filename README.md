# 看尽长安花 · 主题网站

以孟郊《登科后》“春风得意马蹄疾，一日看尽长安花”为主题的古典雅致网页。

## 页面结构

| 页面 | 文件 | 说明 |
|------|------|------|
| 首页 | `index.html` | 主题入口与导航 |
| 春风得意 | `pages/poem.html` | 诗作赏析与登科背景 |
| 长安花事 | `pages/flowers.html` | 唐代长安名花与花事 |
| 文人雅士 | `pages/poets.html` | 相关诗人与作品 |
| 盛世回眸 | `pages/prosperity.html` | 盛唐长安的历史气象 |
| 画意花影 | `pages/gallery.html` | 意境长廊 |

## 使用方法

1. 解压本压缩包
2. 用浏览器直接打开 `index.html` 即可（无需服务器）
3. 每个导航按钮 / 首页按钮均对应独立页面

## 设计特点

- 深色古典配色（墨色 · 金色 · 绯红 · 花瓣粉）
- 飘落花瓣动画
- 响应式布局，适配手机与桌面
- 纯前端实现，无外部依赖，可离线使用
- 每个按钮对应独立完整页面

## 技术栈

- HTML5
- CSS3（变量、动画、Grid、渐变）
- 原生 JavaScript（花瓣效果与导航高亮）
